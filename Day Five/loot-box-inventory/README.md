# Day 5 — Loot Box Inventory & Rarity System

A beginner-friendly upgrade of the Day 4 Loot Box Simulator.

## Project features

- Random rewards
- Reward objects
- Common, Rare and Legendary rarity levels
- Empty-box result
- Boxes-opened counter
- Inventory array
- `push()` to add rewards
- `forEach()` to display inventory
- Clear-inventory button
- Simple CSS animation

## Files

- `index.html`
- `style.css`
- `script.js`

## Run the project

Open `index.html` in a browser.

## Main JavaScript concepts

- Objects
- Arrays
- Functions
- `if...else`
- `Math.random()`
- `push()`
- `forEach()`
- DOM updates
- Click events
