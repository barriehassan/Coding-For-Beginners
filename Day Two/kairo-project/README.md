# Kairo Water Trading Card

This is the main Day 2 class project. It uses only HTML and CSS.

## Files
- `index.html` — the card content
- `style.css` — the card design
- `images/kairo.jpg` — the character image
- `images/reference-kairo.png` — the original design reference

## How to run
1. Open the folder in VS Code.
2. Open `index.html` in a browser.
3. Edit the name, description, stats or colours.
4. Save and refresh the browser.

## Main concepts
- HTML structure
- CSS colours and spacing
- Flexbox
- Border radius and shadow
- Simple hover animation
