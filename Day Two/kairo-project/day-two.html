BUILD JOURNEY

Kairo Project

Start with the final output, then build it step by step using HTML and CSS.

PROJECT OUTPUT

What are we building?

A Trading Card Game character profile.

Project aim

Understand this:

  • Build an engaging character profile layout
  • Use Flexbox for side-by-side stats
  • Style buttons and badges
  • Keep it responsive and clean
Main idea: Structure → Flexbox → Polish

PART 2

CSS turns structure into design

Now we style the card layout, add borders, and use Flexbox to align the stats perfectly.

CSS 1 OF 4

CSS Level 1: The Main Card

Preview: the card shape forms with a blue border

style.css 
.card {
  margin: auto;
  width: 360px;
  background: white;
  border: 8px solid #168ce2;
  border-radius: 25px;
  overflow: hidden;
  box-shadow: 0 14px 30px rgba(0, 91, 170, 0.22);
}
.hero-image {
  width: 100%;
  height: 220px;
  object-fit: cover;
}
Browser preview

Understand this

  • border adds the thick blue outline
  • overflow: hidden stops the image from breaking out of rounded corners
  • object-fit: cover perfectly crops the image
CSS 2 OF 4

CSS Level 2: Typography and Tags

Preview: texts become bold and styled

style.css 
h1 {
  font-size: 46px;
  letter-spacing: 3px;
}
.type {
  display: inline-block;
  padding: 7px 22px;
  color: white;
  background: #087bea;
  border-radius: 20px;
}
Browser preview

Understand this

  • letter-spacing spaces out the title
  • display: inline-block allows the type tag to have padding
  • border-radius creates the pill shape
CSS 3 OF 4

CSS Level 3: Flexbox Stats

Preview: stats align side-by-side horizontally

style.css 
.stats {
  display: flex;
  justify-content: space-between;
  padding: 15px 5px;
  border: 2px solid #9bd8fa;
  border-radius: 16px;
  background: #f4fbff;
}
.stats div {
  flex: 1;
}
Browser preview

Understand this

  • display: flex turns a vertical stack into a row
  • justify-content: space-between pushes columns apart
  • flex: 1 forces each column to be the exact same width
CSS 4 OF 4

CSS Level 4: Special Move & Button

Preview: the card is completely styled

style.css 
.special-move {
  display: flex;
  align-items: center;
  gap: 12px;
  text-align: left;
}
button {
  width: 100%;
  padding: 14px;
  border-radius: 25px;
  color: white;
  background: #078bea;
  cursor: pointer;
}
Browser preview

Understand this

  • align-items: center perfectly aligns the emoji and text
  • width: 100% makes the button fill the card width
  • cursor: pointer changes the mouse to a hand
TESTING

Before we say "finished"

  • The hero image completely covers the top of the card
  • The stats columns are exactly the same width
  • The button fills the bottom of the card
