DAY 3 PROJECT

🎵 Meme Soundboard

Click a button to play a reaction sound.

Now Playing: Choose a sound!
BUILD JOURNEY

Meme Soundboard

Start with the final output, then build it step by step using HTML, CSS and JavaScript.

PROJECT OUTPUT

What are we building?

A soundboard that reacts when a user clicks a button.

Project aim

Understand this:

  • Click a reaction button
  • Play the correct sound
  • Update the "Now Playing" text
  • Keep the page simple and fun
Main idea: Click → Action → Result
HOW IT WORKS

The simple interaction flow

Students should understand the behaviour before writing code.

1
Click

Press a button

2
Detect

JS hears click

3
Play

Audio starts

4
Update

Message changes

PART 3

JavaScript makes it respond

The design is complete. Now we connect button clicks to sounds and messages.

JS 1 OF 3

JS Level 1: Find the message, button and sound

Preview: design stays the same

script.js 
const message = document.getElementById("message");

const wowButton = document.getElementById("wowButton");
const wowSound = document.getElementById("wowSound");
Browser preview

Understand this

  • document means the current webpage
  • getElementById finds an element by ID
  • No visible change yet
JS 2 OF 3

JS Level 2: Listen for a click & Update message

Preview: Now Playing changes to Wow!

script.js 
wowButton.addEventListener("click", function () {
  wowSound.currentTime = 0;
  wowSound.play();
  message.textContent = "Wow!";
});
Browser preview

Understand this

  • addEventListener waits for something
  • "click" is the event we are watching
  • textContent changes the visible text
JS 3 OF 3

JS Level 3: Make a reusable function

Preview: the Wow button still works

script.js 
function playSound(sound, soundName) {
  sound.currentTime = 0;
  sound.play();
  message.textContent = soundName;
}

wowButton.addEventListener("click", function () {
  playSound(wowSound, "Wow!");
});
Browser preview

Understand this

  • A function groups repeated instructions
  • sound and soundName are inputs
  • Now the same logic can support all buttons
TESTING

Before we say "finished"

  • Every button plays the correct sound
  • The Now Playing message changes correctly
  • Rapid clicking restarts the sound
  • The layout works on mobile
  • There are no console errors
