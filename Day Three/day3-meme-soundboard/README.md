# Day 3 Project — Meme Soundboard

This project introduces beginners to JavaScript click events.

## Files

- `index.html` — page content
- `style.css` — colours and layout
- `script.js` — click events and sound playback
- `sounds/` — original practice sound effects

## How to run

1. Open the project folder in VS Code.
2. Open `index.html` in a browser.
3. Click each sound button.

## JavaScript concepts

- `document.getElementById()`
- `addEventListener()`
- `currentTime`
- `play()`
- `textContent`

## Beginner challenge

Change one button's:

- text
- emoji
- colour
- sound name
