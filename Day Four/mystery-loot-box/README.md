# Day 4: Mystery Loot Box

A very simple HTML, CSS and JavaScript project for beginners.

## Files

- `index.html` — page content
- `style.css` — design and animation
- `script.js` — random reward logic

## How to run

1. Open the folder in VS Code.
2. Double-click `index.html` or open it with Live Server.
3. Click **Open Box**.

## Main JavaScript ideas

- `const` stores values.
- An array stores many rewards.
- `Math.random()` creates a random result.
- A function groups instructions.
- `if...else` makes a decision.
- `addEventListener()` listens for a click.

## Easy student changes

Students can change:

- The game title
- Reward names
- Emojis
- Button colour
- Background colour
- Empty-box message
