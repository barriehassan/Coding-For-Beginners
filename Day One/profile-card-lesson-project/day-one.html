BUILD JOURNEY

Profile Card

Start with the final output, then build it step by step using HTML and CSS.

PROJECT OUTPUT

What are we building?

A professional developer profile card.

Project aim

Understand this:

  • Create an attractive layout
  • Absolute positioning for images
  • Responsive typography (clamp)
  • Interactive hover states
Main idea: Structure → Position → Polish
PART 1

HTML builds the structure

First we lay out the text and images. It will look like a plain document at first.

HTML 1 OF 5

HTML Level 1: Basic page skeleton

Preview: a blank browser page

index.html 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Profile Card</title>
</head>
<body>
</body>
</html>
Browser preview

Understand this

  • The browser understands this as an HTML5 document
  • The body is empty, so the page is blank
  • The title appears in the browser tab
HTML 2 OF 5

HTML Level 2: Main card container

Preview: a blank container

index.html 
<body>
  <main class="profile-card">
    <!-- Profile content goes here -->
  </main>
</body>
Browser preview

Understand this

  • tells the browser this is the main content
  • class="profile-card" is a name we give it to style later
  • Nothing is visible yet
HTML 3 OF 5

HTML Level 3: Add the profile photo

Preview: the image appears very large

Browser preview

Understand this

  • adds an image to the page
  • src points to where the image file lives
  • alt describes the image for screen readers

PART 2

CSS turns structure into design

Now we use CSS to position the elements exactly where we want them over a beautiful background.

CSS 1 OF 6

CSS Level 1: Page background and fonts

Preview: the page gets a background color and cleaner font

style.css 
* {
  box-sizing: border-box;
}
body {
  margin: 0;
  min-height: 100vh;
  display: flex;
  background: #eef5fb;
  font-family: Arial, Helvetica, sans-serif;
  color: #081b3a;
}
Browser preview

Understand this

  • * selects everything and fixes how width is calculated
  • body gives the whole page a background color
  • font-family changes the text style globally
CSS 2 OF 6

CSS Level 2: Background and Card size

Preview: card takes shape with a background image

style.css 
.profile-card {
  margin: auto;
  position: relative;
  width: min(100%, 980px);
  aspect-ratio: 1536 / 940;
  background: url("images/background.jpg") center / 100% 100% no-repeat;
}
Browser preview

Understand this

  • width restricts the maximum size
  • aspect-ratio keeps the exact shape
  • background loads the beautiful cover art
CSS 3 OF 6

CSS Level 3: Positioning the Photo

Preview: photo becomes a circle and moves to the left

style.css 
.profile-photo {
  position: absolute;
  left: 6.5%;
  top: 15%;
  width: 31%;
  height: 68%;
  object-fit: cover;
  border: 7px solid white;
  border-radius: 50%;
  box-shadow: 0 10px 25px rgba(0, 58, 140, 0.22);
}
Browser preview

Understand this

  • position: absolute lets us place it exactly
  • border-radius: 50% turns a square into a circle
  • object-fit: cover stops the image from stretching
CSS 4 OF 6

CSS Level 4: Typography and Spacing

Preview: text looks clean and professional

style.css 
h1 {
  font-size: clamp(28px, 5vw, 58px);
}
.level {
  padding: 10px 16px;
  border-radius: 12px;
  background: #0b72d6;
  color: white;
}
.small-line {
  width: 105px;
  height: 5px;
  background: #ffa514;
}
Browser preview

Understand this

  • clamp() makes font size responsive to screen width
  • The .level class styles our small badge
  • The .small-line creates the orange decorative underline
CSS 5 OF 6

CSS Level 5: Social links styling

Preview: social links become interactive buttons

style.css 
.social-links {
  display: flex;
  gap: 18px;
}
.social-links a {
  padding: 13px;
  border-radius: 16px;
  background: white;
  box-shadow: 0 7px 18px rgba(3, 45, 92, 0.16);
  transition: transform 0.2s ease;
}
Browser preview

Understand this

  • display: flex lines the buttons up horizontally
  • box-shadow gives them depth
  • transition prepares the buttons for hover effects
CSS 6 OF 6

CSS Level 6: Hover states and Responsiveness

Preview: the card is interactive and resizes for mobile

style.css 
.profile-card:hover {
  transform: translateY(-8px);
}
.social-links a:hover {
  transform: translateY(-6px) scale(1.05);
}

@media (max-width: 650px) {
  body { padding: 10px; }
  h2 { margin-top: 14px; }
  p { margin: 18px 0 16px; }
  .social-links a { padding: 8px; border-radius: 10px; }
}
Browser preview

Understand this

  • :hover changes how elements look when the mouse is over them
  • transform: translateY() moves elements up slightly
  • @media allows us to change the design on smaller screens
TESTING

Before we say "finished"

  • The profile photo is perfectly circular
  • Social links pop up when hovered
  • The card resizes correctly on smaller screens
